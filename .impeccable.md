## Design Context

### Users
Solo creator / personal tool. The user is the developer — they compress PDFs as part of their own workflow. Context: sitting at a desk, likely during focused work sessions. The app is a utility that should get out of the way and feel satisfying to use.

### Brand Personality
Quiet precision, premium craft, understated confidence. Not flashy, not generic. Like a well-made hand tool — functional, tactile, clearly designed with care.

### Aesthetic Direction
Native macOS DNA with a layer of personality on top. Dark theme is correct for this context. The current Apple HIG palette (#007aff, #1c1c1e system grays) is a starting point — but the app should have slightly warmer tones, a more distinctive typographic voice, and micro-details that make it feel like a considered design rather than an Xcode template. NOT a system settings panel. NOT a generic SaaS dashboard. References: Raycast, Typeface 3, Pastel — apps that feel native but unmistakably themselves.

### Design Principles
1. **Every pixel earns its place** — no decoration without purpose, but purposeful details matter
2. **Speed feels tactile** — compression should feel fast and satisfying, not just functional
3. **Information density without clutter** — this is a utility, not a content app; show what's needed, hide what isn't
4. **Premium in the details** — the 5% of visual choices that separate good from great: icon quality, type rhythm, interaction feedback
5. **Calm confidence** — no anxiety-inducing UI moments; the user should always know what's happening
